Подтвердите вход

Генератор кодов TOTP

Коды из генератора заменят письма при входе с паролем. Они подтверждают вход, но не являются ключом шифрования файлов.

Добавьте этот секрет в синхронизируемый генератор: тип TOTP, 6 цифр, SHA-1, период 30 секунд. Секрет показывается только при настройке.

Если генератор утрачен, войдите с passkey. Сброс всех способов доступа через почту удаляет файлы.
